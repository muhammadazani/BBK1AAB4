Katalog Skema Pemrograman

Pola solusi yang dipakai ulang untuk memecahkan soal pemrograman

Saat membaca soal baru, programmer berpengalaman jarang mulai dari nol. Mereka mengenali tujuan soal (“hitung berapa yang lulus”), mengingat pola solusi yang cocok (“penghitung mulai 0, kunjungi setiap item, tambah 1 jika memenuhi”), lalu menyesuaikannya. Pola solusi seperti ini disebut skema (Soloway & Ehrlich, 1984). Halaman ini mengumpulkan 39 skema yang kamu butuhkan di mata kuliah ini, masing-masing dalam satu kartu.

Skema bukan kode untuk disalin. Skema adalah rencana: urutan langkah yang kamu tulis sebagai komentar, lalu kamu isi dengan kode yang sesuai soalmu.

Cara Memakai Katalog

1

Baca soalnya, cari tujuannya. Garis bawahi kata-kata yang menyatakan hasil: berapa banyak, total, terbesar, adakah, semua. Tiap kartu punya bagian Ciri soal berisi kata-kata seperti ini.

2

Pilih skemanya. Jawab pertanyaan di tabel Skema mana yang dibutuhkan?. Jawabanmu menunjuk ke satu kode kartu, misalnya D1.

3

Buka kartunya dan tulis langkahnya sebagai komentar. Salin daftar Langkah ke editor sebagai komentar #, sebelum menulis satu baris kode pun.

4

Isi tiap langkah dengan kode. Lihat Kerangka kode bila perlu, lalu ganti nama-nama umum (koleksi, kondisi) dengan data dan syarat soalmu.

5

Uji, lalu gabungkan. Uji dengan contoh yang kamu hitung tangan, termasuk nilai batas. Soal tugas biasanya butuh beberapa skema; lihat Menggabungkan skema.

Contoh: soal laundry Minggu 5

Tarif reguler Rp6.000/kg, kilat Rp9.000/kg, express Rp15.000/kg. Potongan Rp5.000 jika berat lebih dari 4 kg, kecuali express. Hitung total bayar.

Bagian soal Pertanyaan pemilih Skema
Tarif bergantung pada jenis layanan Hasil bergantung pada beberapa pilihan? B3 · Klasifikasi bertingkat
Potongan bergantung pada berat dan layanan Dua faktor yang saling lepas? B4 · Keputusan bersarang, digabung dengan and
Total = tarif × berat − potongan Ada rumus, tanpa perulangan? A1 · Baca–Proses–Hasilkan

Tiap skema menjadi satu fungsi, dan langkah-langkah kartunya menjadi komentar:

def tarif_layanan(layanan):
    # B3: urutkan kategori, tepat satu cabang berjalan, else untuk sisanya
    if layanan == "reguler":
        return 6000
    elif layanan == "kilat":
        return 9000
    else:
        return 15000

def potongan(berat, layanan):
    # B4: dua faktor digabung dengan and; uji nilai batas 4 kg
    if berat > 4 and layanan != "express":
        return 5000
    else:
        return 0

def total_bayar(layanan, berat):
    # A1: siapkan data, hitung dengan rumus, kembalikan hasilnya
    biaya = tarif_layanan(layanan) * berat
    return biaya - potongan(berat, layanan)

print(total_bayar("reguler", 5))    # 25000
TipTiga kebiasaan saat memakai kartu
  • Perhatikan “Sering tertukar dengan”. Kesalahan paling umum adalah memakai skema yang mirip tetapi salah, misalnya menghitung (D1) padahal soal meminta total (D2).
  • Tanyakan: bisakah perulangannya berhenti lebih awal? Mencari (D6), adakah (D7), dan semuakah (D8) boleh berhenti di item penentu pertama. Menghitung, menjumlah, nilai ekstrem, menyaring, dan mengubah harus mengunjungi setiap item.
  • Sesuaikan dengan minggumu. Setiap kartu menyebut minggu kapan skema itu dipelajari. Pakai filter di bawah untuk menampilkan skema yang sudah bisa kamu pakai.

Jawab pertanyaan ini sebelum menulis kode. Jawabanmu menunjuk ke sebuah skema.

Hasil bergantung pada satu kondisi? Beberapa rentang? Dua faktor? Satu / rentang / dua faktor B2 / B3 / B4

Tidak, berhenti pada masukan khusus C2
Tidak, berhenti saat target tercapai C4

Total atau hasil kali D2
Rata-rata D3
Nilai terbesar atau terkecil D4
Item mana yang terbesar D5
Item pertama yang cocok, atau posisinya D6 (F2 jika data terurut)
True/False: adakah …? D7
True/False: semuakah …? D8
List baru berisi sebagian item D9
List baru dengan setiap item diubah D10

Kartu Skema

Skema bertanda ★ inti paling sering muncul di soal dan wajib kamu kuasai. Kode di kerangka memakai nama umum seperti koleksi, kondisi, dan proses; ganti dengan nama yang sesuai soalmu.

A · Urutan (Sequence)

Perhitungan lurus: tanpa keputusan, tanpa perulangan.

A1 ★ inti

Baca–Proses–Hasilkan Input–process–output

Menghitung hasil dari nilai yang diketahui dengan rumus atau urutan langkah yang tetap.

Ciri soal

hitung … dari … konversi … berapa (total/luas/biaya) jika … ada rumus

Langkah

  1. Kenali masukan dan keluarannya
  2. Ubah data ke satuan yang dibutuhkan rumus
  3. Hitung hasilnya dengan rumus
  4. Kembalikan hasilnya

Minggu 2 · sebagai fungsi mulai Minggu 5

Kerangka kode 
def nama_fungsi(masukan_1, masukan_2):
    # 1. Siapkan data (ubah satuan jika perlu)
    # 2. Hitung dengan rumus
    hasil = ...
    # 3. Kembalikan hasilnya
    return hasil

A2

Tukar nilai Swap

Menukar nilai dua variabel tanpa kehilangan salah satunya.

Ciri soal

tukar urutkan dua nilai agar a ≤ b langkah di dalam pengurutan

Langkah

  1. Simpan satu nilai di variabel sementara
  2. Timpa variabel itu dengan nilai yang lain
  3. Pindahkan nilai yang disimpan ke variabel kedua

Minggu 2

Kerangka kode 
sementara = a
a = b
b = sementara

A3

Pecah dengan div dan mod Unit decomposition with div and mod

Memecah satu besaran menjadi satuan besar dan kecil (jam/menit/detik, lembar uang, puluhan dan satuan).

Ciri soal

ubah … menjadi jam, menit, detik pecah nominal menjadi lembar uang berapa … yang muat sisa

Langkah

  1. Ambil jumlah satuan terbesar dengan //
  2. Simpan sisanya dengan %
  3. Ulangi untuk satuan berikutnya yang lebih kecil
  4. Kembalikan semua bagiannya

Sering tertukar dengan D16 · Kupas digit

Minggu 2

Kerangka kode 
besar = total // satuan_besar
sisa = total % satuan_besar
kecil = sisa // satuan_kecil
sisa = sisa % satuan_kecil

B · Seleksi (Selection)

Memilih tindakan berdasarkan kondisi.

B1 ★ inti

Penjaga Guard

Menangani kasus yang tidak valid atau khusus lebih dulu lalu keluar, sehingga perhitungan utama hanya menerima data yang valid.

Ciri soal

jika data tidak valid … ada pembagian (mungkin dengan nol) nilai negatif tidak boleh kembalikan None / −1 / pesan

Langkah

  1. Daftar kasus yang membuat perhitungan utama mustahil atau tidak bermakna
  2. Periksa kasus itu lebih dulu dan langsung return
  3. Tulis perhitungan utama untuk kasus yang valid

Sering tertukar dengan B2 · Pilih salah satu

Minggu 3 · di dalam fungsi mulai Minggu 5

Kerangka kode 
def nama_fungsi(data):
    # 1. Penjaga: tangani kasus tidak valid lebih dulu
    if kondisi_tidak_valid:
        return nilai_khusus
    # 2. Kasus normal
    ...
    return hasil

B2 ★ inti

Pilih salah satu Two-way decision

Memilih tepat satu dari dua tindakan atau dua rumus.

Ciri soal

jika … maka …, selain itu … lulus / tidak lulus tarif berubah setelah ambang tertentu

Langkah

  1. Temukan kondisi yang memisahkan dua kasus, termasuk nilai batasnya
  2. Tulis tindakan untuk kasus benar
  3. Tulis tindakan untuk kasus salah

Sering tertukar dengan B3 · Klasifikasi bertingkat

Minggu 3

Kerangka kode 
if kondisi:
    hasil = rumus_1
else:
    hasil = rumus_2

B3 ★ inti

Klasifikasi bertingkat Multi-way classification

Memasukkan satu nilai ke salah satu dari beberapa kategori yang berurutan (rentang).

Ciri soal

kategori nilai huruf golongan / kelas tarif bertingkat tabel rentang

Langkah

  1. Tulis rentangnya sebagai tabel; periksa celah dan tumpang tindih
  2. Urutkan kondisi dari satu ujung (tertinggi atau terendah)
  3. Pakai if–elif–else agar tepat satu cabang yang berjalan
  4. Pakai else untuk kategori terakhir

Sering tertukar dengan B4 · Keputusan bersarang · B5 · Tabel rujukan

Minggu 3

Kerangka kode 
if nilai >= batas_1:
    kategori = "K1"
elif nilai >= batas_2:
    kategori = "K2"
else:
    kategori = "K3"

B4

Keputusan bersarang Nested decision (two factors)

Mengambil keputusan saat hasilnya bergantung pada dua kondisi atau lebih yang saling lepas.

Ciri soal

bergantung pada … dan … jika member dan … tabel dua dimensi

Langkah

  1. Buat tabel semua kombinasi kondisi
  2. Putuskan: bersarang (faktor luar, lalu dalam) atau digabung dengan and/or
  3. Periksa bahwa setiap kombinasi punya tepat satu hasil

Sering tertukar dengan B3 · Klasifikasi bertingkat

Minggu 3

Kerangka kode 
if faktor_1:
    if faktor_2:
        hasil = ...
    else:
        hasil = ...
else:
    ...

B5

Tabel rujukan Lookup table

Memetakan nilai-nilai diskret ke hasilnya dengan dictionary, bukan rantai if–elif yang panjang.

Ciri soal

kode → nama nomor hari atau bulan harga per jenis banyak kasus yang membandingkan kesamaan

Langkah

  1. Tulis pemetaannya sebagai data (dictionary)
  2. Cari kuncinya
  3. Tangani kunci yang tidak ada dengan nilai bawaan

Sering tertukar dengan B3 · Klasifikasi bertingkat

Minggu 12 (dictionary)

Kerangka kode 
TABEL = {kunci_1: nilai_1, kunci_2: nilai_2}
hasil = TABEL.get(kunci, nilai_bawaan)

C · Kendali perulangan

Mengatur kapan perulangan berjalan dan kapan berhenti.

C1 ★ inti

Ulangi n kali Counted repetition

Mengulang suatu pembaruan sebanyak jumlah yang sudah diketahui sebelum perulangan dimulai.

Ciri soal

selama n tahun/bulan/kali untuk setiap bilangan dari 1 sampai n jumlah pengulangan diberikan

Langkah

  1. Siapkan keadaan yang berubah
  2. Ulangi pembaruan tepat n kali dengan range
  3. Kembalikan keadaan akhirnya

Sering tertukar dengan C4 · Ulangi sampai tercapai

Minggu 6

Kerangka kode 
keadaan = nilai_awal
for i in range(n):
    keadaan = perbarui(keadaan)

C2 ★ inti

Baca sampai tanda berhenti Sentinel-controlled loop

Memproses masukan satu per satu sampai muncul nilai penanda berhenti.

Ciri soal

masukkan 0 / −1 untuk selesai sampai pengguna mengetik … banyaknya masukan tidak diketahui

Langkah

  1. Baca nilai pertama sebelum perulangan
  2. Selama nilai itu bukan penanda: proses
  3. Baca nilai berikutnya di akhir badan perulangan
  4. Setelah perulangan, laporkan hasilnya

Sering tertukar dengan C3 · Minta ulang sampai benar · C4 · Ulangi sampai tercapai

Minggu 6

Kerangka kode 
nilai = baca()
while nilai != PENANDA:
    proses(nilai)
    nilai = baca()

C3

Minta ulang sampai benar Input validation loop

Terus meminta masukan sampai masukannya valid.

Ciri soal

jika masukan salah, minta lagi harus antara … dan … ulangi sampai valid

Langkah

  1. Baca satu nilai
  2. Selama tidak valid: tampilkan pesan dan baca lagi
  3. Kembalikan nilai yang valid

Sering tertukar dengan B1 · Penjaga · C2 · Baca sampai tanda berhenti

Minggu 6

Kerangka kode 
nilai = baca()
while tidak_valid(nilai):
    tampilkan_pesan()
    nilai = baca()

C4

Ulangi sampai tercapai Loop until a condition is reached

Mengulang pembaruan sampai keadaan target tercapai, sambil menghitung langkahnya bila perlu.

Ciri soal

berapa tahun sampai … sampai melebihi … jumlah pengulangan adalah jawabannya

Langkah

  1. Penjaga: pastikan target bisa tercapai (tidak berulang selamanya)
  2. Siapkan keadaan dan penghitung langkah
  3. Selama target belum tercapai: perbarui dan hitung
  4. Kembalikan penghitungnya

Sering tertukar dengan C1 · Ulangi n kali

Minggu 6

Kerangka kode 
langkah = 0
while belum_tercapai(keadaan):
    keadaan = perbarui(keadaan)
    langkah = langkah + 1

C5

Perulangan menu Menu loop

Menampilkan pilihan berulang kali dan menjalankan pilihan pengguna sampai ia memilih keluar.

Ciri soal

tampilkan menu pilih 1–4 program berjalan sampai pengguna memilih keluar

Langkah

  1. Siapkan keadaan program
  2. Ulangi: tampilkan menu dan baca pilihan
  3. Jalankan pilihan dengan if–elif (satu cabang per opsi, plus pilihan tak dikenal)
  4. Berhenti saat opsi keluar dipilih

Sering tertukar dengan C2 · Baca sampai tanda berhenti

Minggu 9 (atau praktikum Minggu 7)

Kerangka kode 
pilihan = ""
while pilihan != PILIHAN_KELUAR:
    tampilkan_menu()
    pilihan = input()
    if pilihan == "1": ...
    elif pilihan == "2": ...

D · Satu kali telusur data

Mengunjungi setiap item satu kali untuk menghasilkan satu jawaban.

D1 ★ inti

Menghitung Counting

Menghitung berapa banyak item yang memenuhi suatu kondisi.

Ciri soal

berapa banyak … jumlah mahasiswa yang … jawabannya bilangan bulat cacah

Langkah

  1. Siapkan penghitung bernilai 0
  2. Kunjungi setiap item
  3. Uji kondisinya
  4. Tambah 1 jika kondisinya benar
  5. Kembalikan penghitung setelah perulangan

Sering tertukar dengan D2 · Akumulasi · D6 · Cari yang pertama · D7 · Adakah?

Minggu 6 · lagi pada string (10) dan list (11)

Kerangka kode 
banyak = 0
for item in koleksi:
    if kondisi(item):
        banyak = banyak + 1
return banyak

D2 ★ inti

Akumulasi Accumulation (sum or product)

Menggabungkan semua nilai menjadi satu hasil: total, hasil kali, atau gabungan.

Ciri soal

total jumlah semua … hasil kali … faktorial jawabannya menggabungkan nilai-nilainya

Langkah

  1. Siapkan akumulator dengan nilai identitas (0 untuk jumlah, 1 untuk hasil kali)
  2. Kunjungi setiap item
  3. Gabungkan item ke akumulator
  4. Kembalikan akumulatornya

Sering tertukar dengan D1 · Menghitung

Minggu 6

Kerangka kode 
hasil = IDENTITAS   # 0 untuk +, 1 untuk ×
for item in koleksi:
    hasil = hasil OPERASI item
return hasil

D3 ★ inti

Rata-rata Average

Menghitung rata-rata nilai yang memenuhi kondisi, dengan aman.

Ciri soal

rata-rata rata-rata … yang … mean

Langkah

  1. Siapkan jumlah dan penghitung
  2. Kunjungi setiap item; untuk item yang memenuhi, tambahkan ke jumlah dan penghitung
  3. Jaga agar tidak membagi dengan nol
  4. Kembalikan jumlah / penghitung

Minggu 6

Kerangka kode 
total = 0
banyak = 0
for item in koleksi:
    if kondisi(item):
        total = total + item
        banyak = banyak + 1
if banyak == 0:
    return 0
return total / banyak

D4 ★ inti

Nilai terbesar / terkecil Extreme value

Menemukan nilai terbesar atau terkecil.

Ciri soal

terbesar tertinggi termurah maksimum / minimum

Langkah

  1. Penjaga: koleksi kosong tidak punya nilai ekstrem
  2. Mulai dengan item pertama sebagai yang terbaik
  3. Kunjungi item lainnya; ganti yang terbaik jika ada item yang mengalahkannya
  4. Kembalikan yang terbaik

Sering tertukar dengan D5 · Posisi terbesar · D12 · Bandingkan dengan sebelumnya

Minggu 9 · lagi pada list (11)

Kerangka kode 
terbaik = koleksi[0]
for item in koleksi:
    if item > terbaik:
        terbaik = item
return terbaik

D5

Posisi terbesar Position of the extreme

Menemukan di mana nilai terbesar atau terkecil berada, atau milik item yang mana.

Ciri soal

siapa yang paling … di posisi ke berapa nama produk termurah

Langkah

  1. Jaga dari koleksi kosong
  2. Simpan posisi item terbaik sejauh ini (mulai dari 0)
  3. Kunjungi posisi 1..n−1 dan bandingkan dengan item di posisi terbaik
  4. Kembalikan posisinya atau item terkait

Sering tertukar dengan D4 · Nilai terbesar / terkecil · D6 · Cari yang pertama

Minggu 11 (butuh list)

Kerangka kode 
pos_terbaik = 0
for i in range(1, len(data)):
    if data[i] > data[pos_terbaik]:
        pos_terbaik = i

D6 ★ inti

Cari yang pertama Linear search

Menemukan item pertama (atau posisinya) yang cocok, dan berhenti begitu ketemu.

Ciri soal

cari di mana … posisi pertama … item pertama yang …

Langkah

  1. Kunjungi item secara berurutan
  2. Begitu ada yang cocok, langsung kembalikan item (atau posisinya)
  3. Setelah perulangan, kembalikan nilai ‘tidak ditemukan’

Sering tertukar dengan D1 · Menghitung · D7 · Adakah?

Minggu 9 · string (10) · list (11)

Kerangka kode 
for i in range(len(data)):
    if cocok(data[i]):
        return i
return -1

D7 ★ inti

Adakah? Existence check (any)

Menjawab apakah setidaknya satu item memenuhi kondisi.

Ciri soal

adakah … apakah memuat … setidaknya satu jawabannya True/False

Langkah

  1. Kunjungi item
  2. Kembalikan True pada item pertama yang memenuhi kondisi
  3. Setelah perulangan, kembalikan False

Sering tertukar dengan D8 · Semuakah? · D1 · Menghitung

Minggu 9 · lagi di Minggu 10–11

Kerangka kode 
for item in koleksi:
    if kondisi(item):
        return True
return False

D8 ★ inti

Semuakah? Universal check (all)

Menjawab apakah semua item memenuhi kondisi.

Ciri soal

apakah semua … setiap … tidak ada satu pun … jawabannya True/False

Langkah

  1. Kunjungi item
  2. Kembalikan False pada contoh penyangkal pertama
  3. Setelah perulangan, kembalikan True

Sering tertukar dengan D7 · Adakah?

Minggu 9 · lagi di Minggu 10–11

Kerangka kode 
for item in koleksi:
    if not kondisi(item):
        return False
return True

D9 ★ inti

Saring Filter

Membuat koleksi baru berisi item-item yang memenuhi kondisi.

Ciri soal

ambil semua … yang … daftar … yang … tampilkan hanya …

Langkah

  1. Mulai dengan list hasil yang kosong
  2. Kunjungi setiap item
  3. Tambahkan item ke hasil jika kondisinya benar
  4. Kembalikan list hasil

Sering tertukar dengan D10 · Ubah setiap elemen · D1 · Menghitung

Minggu 11 (butuh list)

Kerangka kode 
hasil = []
for item in koleksi:
    if kondisi(item):
        hasil.append(item)
return hasil

D10

Ubah setiap elemen Map (transform each item)

Membuat koleksi baru yang setiap itemnya diubah dengan cara yang sama.

Ciri soal

ubah setiap … konversi semua … list baru berisi …

Langkah

  1. Mulai dengan list hasil yang kosong
  2. Kunjungi setiap item
  3. Ubah item itu dan tambahkan hasilnya
  4. Kembalikan list hasil

Sering tertukar dengan D9 · Saring

Minggu 11 (butuh list)

Kerangka kode 
hasil = []
for item in koleksi:
    hasil.append(ubah(item))
return hasil

D11

Bangun teks String building

Membangun string baru sepotong demi sepotong.

Ciri soal

balik kata inisial / singkatan sembunyikan sebagian huruf gabungkan …

Langkah

  1. Mulai dengan string kosong
  2. Kunjungi setiap karakter (atau potongan)
  3. Tambahkan potongan di depan atau di belakang
  4. Kembalikan string-nya

Sering tertukar dengan D10 · Ubah setiap elemen

Minggu 10 (string)

Kerangka kode 
hasil = ""
for huruf in teks:
    hasil = hasil + ubah(huruf)    # atau: ubah(huruf) + hasil

D12

Bandingkan dengan sebelumnya Compare with the previous item

Memakai setiap item bersama item sebelumnya.

Ciri soal

Menggabungkan Skema

Kebanyakan soal tugas membutuhkan beberapa skema sekaligus. Ada tiga cara menggabungkannya:

Cara Artinya Contoh
Berurutan Satu skema selesai, lalu skema berikutnya dimulai Cari rata-rata (D3), lalu hitung nilai di atas rata-rata (D1): dua kali telusur
Bersarang Satu skema berjalan di dalam setiap langkah skema lain Uji bilangan prima (G1) di dalam penghitungan (D1)
Digabung Dua skema berbagi satu perulangan Menghitung dan menjumlah dalam satu telusur untuk rata-rata (D3); penjaga (B1) di dalam perulangan

Contoh (memakai list, yang dipelajari di Minggu 11). Tulis rata_rata_lulus(daftar_nilai) yang mengembalikan rata-rata nilai yang lulus (≥ 60), mengabaikan nilai tidak valid (di bawah 0 atau di atas 100). Kembalikan 0 jika tidak ada yang lulus.

def rata_rata_lulus(daftar_nilai):
    total = 0                          # D2: akumulator
    banyak = 0                         # D1: penghitung
    for nilai in daftar_nilai:
        if 0 <= nilai <= 100:          # B1: penjaga data tidak valid
            if nilai >= 60:            # D1/D2: kondisi
                total = total + nilai
                banyak = banyak + 1
    if banyak == 0:                    # B1: penjaga pembagian
        return 0
    return total / banyak              # D3: rata-rata
Uji Hasil
rata_rata_lulus([70, 80, 150, -5, 50]) 75.0
rata_rata_lulus([10, 20]) 0
rata_rata_lulus([]) 0

Beri label setiap bagian dengan skema asalnya, seperti komentar di atas. Label ini membantumu (dan pemeriksa kodemu) melihat rencana di balik kode.

Peran Variabel

Hampir semua variabel di program pemula memainkan salah satu dari beberapa peran berikut (Sajaniemi, 2002). Menyebut perannya membantu menjelaskan kode (“terbaik adalah nilai terbaik sejauh ini”) dan mengenali skemanya.

Peran Tugasnya Contoh
Nilai tetap Diberi nilai sekali, tidak pernah berubah batas_lulus = 60
Pelangkah Melewati urutan nilai yang dapat ditebak for i in range(n); n yang mengecil di D16
Penjelajah Bergerak melewati posisi-posisi struktur data i pada data[i]; kiri/kanan di F1
Pemegang terbaru Menyimpan nilai terakhir yang dibaca harga = int(input()) di C2
Pemegang terbaik Menyimpan nilai (atau posisi) terbaik sejauh ini terbaik di D4
Pengumpul Mengumpulkan pengaruh nilai-nilai yang dilihat total, banyak
Pengikut Menyimpan nilai sebelumnya dari variabel lain data[i - 1] di D12
Bendera satu arah Boolean yang berubah sekali dan tidak kembali ketemu = True
Sementara Menyimpan nilai untuk waktu yang sangat singkat sementara di A2
Wadah Struktur data yang menyimpan atau menata item list hasil di D9, dictionary di D15
